# Mark Adrian Remigio — Portfolio

A responsive, data-driven portfolio showcasing my web and game development projects, education, experience, skills, and certifications. Built with plain HTML, CSS, and JavaScript, with a custom brick-inspired visual identity.

**Live portfolio:** [adrianremigio.dev](https://adrianremigio.dev)

## Features

- Responsive layout for desktop and mobile
- Project gallery with detailed descriptions, screenshots, and external links
- Sections for education, experience, organizations, certifications, and skills
- Interactive portfolio ID card and image showcases
- GitHub activity statistics
- Downloadable resume
- Accessible navigation and reduced-motion support

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

No framework, package dependencies, or build step required.

## Run locally

Clone the repository and start a local static server:

```sh
git clone https://github.com/Remigio2004/portfolio-mark-remigio.git
cd portfolio-mark-remigio
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). Alternatively, open `index.html` directly; a local server is recommended for browser features that rely on network requests.

## Project structure

```text
index.html       Page structure
css/style.css    Visual design and responsive styles
js/script.js     Portfolio content, rendering, and interactions
assets/          Images, project screenshots, icons, and other media
Remigio_Resume.pdf  Downloadable resume
```

Portfolio content is maintained in the data arrays near the top of `js/script.js`.
